#  Taller de Encapsulación - Cuenta Bancaria

Este proyecto fue desarrollado en Python como práctica del concepto de **encapsulación** en Programación Orientada a Objetos (POO).

---

##  Descripción

Se crea una clase llamada `CuentaBancaria` que permite simular operaciones básicas de una cuenta bancaria como:

- Consultar titular
- Consultar saldo
- Depositar dinero
- Retirar dinero con validación

El objetivo es aplicar encapsulación usando atributos privados y propiedades.

---

##  Conceptos aplicados

- Clases y objetos
- Encapsulación
- Atributos privados (`_titular`, `_saldo`)
- Propiedades (`@property` y `@setter`)
- Validaciones con condiciones
- Manejo básico de errores
